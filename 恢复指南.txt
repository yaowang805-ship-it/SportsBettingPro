本指南分为两部分：
  【一】紧急抢救（旧电脑还能开机）
  【二】新电脑重建（旧电脑已无法使用）

【一】紧急抢救（旧电脑还能开机时做）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 把项目推送到 GitHub（先确认有网络）：

   cd ~/Desktop/SportsBettingPro
   git add .
   git commit -m "应急备份 2026-06-24"
   git push origin main

2. 备份以下几个文件到 U 盘或 iCloud：

   ┌──────────────────────────────────────────────┬──────────────────┐
   │ 文件/目录                                     │ 为什么重要        │
   ├──────────────────────────────────────────────┼──────────────────┤
   │ SportsBettingPro/.env                        │ 所有 API 密钥     │
   │ SportsBettingPro/data/storage/               │ 虚拟组合/投注记录  │
   │ SportsBettingPro/database.sqlite             │ 历史数据库        │
   │ SportsBettingPro/data                        │ 赔率缓存/扫描结果  │
   │ ~/.claude/projects/...memory/                │ AI 记忆（重要！）  │
   │ ...SportsBettingPro/MEMORY.md                │                    │
   └──────────────────────────────────────────────┴──────────────────┘

   记忆文件具体位置：
   ~/.claude/projects/-Users-wangyao-Desktop-SportsBettingPro/memory/

   拷贝命令示例（到 U 盘）：
   cp ~/Desktop/SportsBettingPro/.env /Volumes/USB/
   cp -r ~/Desktop/SportsBettingPro/data/storage /Volumes/USB/
   cp ~/Desktop/SportsBettingPro/database.sqlite /Volumes/USB/
   cp -r ~/.claude/projects/-Users-wangyao-Desktop-SportsBettingPro/memory /Volumes/USB/

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【二】新电脑重建
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

步骤 1：安装 Claude Code

   打开终端（Terminal），执行：
   npm install -g @anthropic-ai/claude-code

   安装后验证：
   claude --version

步骤 2：从 GitHub 拉取代码

   cd ~/Desktop
   git clone https://github.com/yaowang805-ship-it/SportsBettingPro.git
   cd SportsBettingPro

   注意：如果 git 提示需要登录，用 GitHub 用户名 yaowang805-ship-it
   和个人访问令牌（token）作为密码登录。

步骤 3：恢复 .env 配置文件（密钥）

   从备份（U盘/iCloud）复制回项目目录：
   cp /Volumes/USB/.env ~/Desktop/SportsBettingPro/.env

   如果没有备份，需要重新申请以下密钥：
   ┌─────────────────────┬────────────────────────────────┐
   │ 用途                │ 获取地址                       │
   ├─────────────────────┼────────────────────────────────┤
   │ BSD_API_KEY         │ BSD API（已配置免费无限量）     │
   │ DINGTALK_WEBHOOK    │ 钉钉机器人 Webhook              │
   │ ODDS_API_KEY        │ the-odds-api（配额已耗尽，备用）│
   │ FOOTBALL_API_KEY    │ football-data.org               │
   │ BSD_API_KEY=2034... │ 已经在 .env 里，备份好就行      │
   └─────────────────────┴────────────────────────────────┘

步骤 4：恢复数据文件

   cp -r /Volumes/USB/storage ~/Desktop/SportsBettingPro/data/storage
   cp /Volumes/USB/database.sqlite ~/Desktop/SportsBettingPro/
   cp -r /Volumes/USB/data ~/Desktop/SportsBettingPro/

步骤 5：恢复 AI 记忆（在终端中执行）

   先进入项目目录启动 Claude Code：
   cd ~/Desktop/SportsBettingPro
   claude

   第一次启动后退出 Claude Code，然后恢复记忆文件：
   mkdir -p ~/.claude/projects/-Users-wangyao-Desktop-SportsBettingPro/memory
   cp -r /Volumes/USB/memory/* ~/.claude/projects/-Users-wangyao-Desktop-SportsBettingPro/memory/

   或者复制整个 memory 目录：
   cp -r /Volumes/USB/memory ~/.claude/projects/-Users-wangyao-Desktop-SportsBettingPro/

步骤 6：安装 Python 依赖

   退出 Claude Code（如果还在），在终端中执行：
   cd ~/Desktop/SportsBettingPro
   pip3 install -r requirements.txt
   python3 -m playwright install chromium

   如果项目没有 requirements.txt，可以先生成：
   pip3 freeze > requirements.txt
   然后在旧电脑上备份这个文件，新电脑上恢复。

步骤 7：验证环境

   在项目目录下执行：
   python3 -c "from fetchers.bsd_fetcher import fetch_upcoming_events; print('BSD API:', len(fetch_upcoming_events()))"
   python3 -c "from src.betting.paper_trader import PaperTrader; PaperTrader().print_report()"

   如果看到数据，说明恢复成功。

步骤 8：启动循环监控

   cd ~/Desktop/SportsBettingPro
   python3 scripts/live_monitor.py --loop --dingtalk --betting &

   放入后台持续运行。

【重要说明】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. AI 记忆 = 我对你的所有了解
   每次你重新开 Claude Code，我会读记忆文件来恢复上下文。
   如果记忆文件没恢复，我会像第一次见面一样，需要重新了解
   项目背景。

2. .env 文件包含密钥
   这个文件不能上传到 GitHub。换了新电脑必须从备份恢复，
   或者手动重新填写。

3. 钉钉推送依赖 webhook 地址
   如果换了新电脑没恢复 .env，钉钉推送会失效。

4. 循环监控需要保持在后台
   每次重启电脑后，需要手动执行：
   cd ~/Desktop/SportsBettingPro && python3 scripts/live_monitor.py --loop --dingtalk --betting &

5. 虚拟投注数据不会丢
   投注记录存在 data/storage/virtual_portfolio.json 里，
   只要恢复了这个文件，所有待结算和历史记录都在。
